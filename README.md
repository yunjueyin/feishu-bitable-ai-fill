# AI 批量填表（飞书多维表自定义插件）

按一份「总要求」（给 AI 的输出约束）逐行调用大模型，把按标记分点的答案自动拆分并写入右侧自动创建的「多行文本」列。

## 功能

- **总要求编辑**：粘贴给 AI 的约束（如"输出 5 个要点、每条≤30字"），支持多套模板本地保存 + 导出/导入 JSON（不含密钥）。
- **模型接入**：任意 OpenAI 兼容端点（DeepSeek / 智谱 / 月之暗面 / 硅基流动 / 通义 / OpenAI…），Base URL + API Key + 模型名存浏览器 localStorage。
- **试跑首行**：先对首行生成并预览分点结构，确认列名后再批量，不写回。
- **自动建列**：按首行实际分点数幂等创建 输出1…输出N（多行文本，重名复用 / 类型不符跳过并警告；建在表尾，飞书不支持 API 指定列位置，可手动拖动）。
- **批量执行**：并发可调（默认 3）、429/5xx 指数退避、进度条 + ETA、随时取消（已完成保留）、失败项一键重跑。
- **容错**：分点超列截断、不足留空并计数警告；整批写失败自动降级逐格写并定位坏行。

## 使用

1. 部署后把 Pages 地址填入飞书多维表「自定义组件 / 插件」（见 [DEPLOY.md](./DEPLOY.md)）。
2. 填模型配置 → 粘贴总要求 → 选源字段。
3. 「试跑首行」看预览 → 确认列名 → 「确认并开始批量生成」。

> 分点标记默认 `【1】…【2】…`，可在界面切换为 `[1]` / `1.` / `一、`。总要求里建议写明"按【1】【2】编号输出分点"以保证解析稳定。

## 开发

```bash
npm install
npm run dev          # 本地开发
npm run build        # 构建 dist/
node test_runner.mjs # 46 项零框架回归测试（托管 node 完整路径运行）
```

## 结构

```
src/
  feishu.js  # SDK 封装：分页读记录(viewId 保序)、ensureColumns 幂等建列、writeTextCell 双格式兜底
  llm.js     # OpenAI 兼容 /chat/completions，重试分类（429/5xx 重试，401/400 直接抛）
  parser.js  # 分点解析：标记主策略 + [n]/n./一、/空行 启发式兜底
  runner.js  # 编排：试跑→建列→并发池→写回→失败收集（依赖注入，可 Node mock 测试）
  prompt.js  # system=总要求+格式契约；user=素材
  storage.js # 配置/模板 localStorage（版本校验、导出剔除密钥）
  main.js/ui.js/styles.css  # UI（原生 DOM，零 UI 库）
public/probe.html  # 飞书环境探针：实测 addField 返回 / 写入格式 / 读取结构 / 延迟容忍
```
