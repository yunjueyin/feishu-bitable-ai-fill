# 飞书多维表 · AI 批量填表插件

在飞书多维表中，按一份「总要求」（给 AI 的输出约束），逐行调用大模型生成分点内容，自动创建输出列并批量写回。

## 功能

1. **源字段**：选定一列，每行该列内容作为素材喂给 AI。
2. **总要求**：粘贴给 AI 的约束（如"输出 5 个要点、每条≤30 字、口语化"），支持多套模板保存 / 导出 / 导入 JSON（不含 API Key）。
3. **试跑首行**：预览 AI 输出与分点解析结果，可改列名后确认。
4. **自动建列**：按首行分点数创建「多行文本」列（输出1…输出N），幂等（已存在同名多行文本列直接复用）。
5. **批量执行**：可配置并发（默认 3）、进度 / ETA / 取消、失败收集与一键重跑、可选跳过已有内容。
6. **模型**：任意 OpenAI 兼容端点（DeepSeek / 智谱 / 月之暗面 / 硅基流动 / 通义 / OpenAI…），Base URL + API Key + 模型名，存本浏览器 localStorage。

## 使用

1. 飞书多维表 → 扩展 / 自定义组件 → 添加本插件（填入部署后的 URL）。
2. 依次完成：选源字段 → 填模型配置 → 粘贴总要求（约定模型用 `【1】【2】…` 分点输出）→ 试跑首行 → 确认列名 → 开始批量生成。
3. 失败行可「重跑失败项」；新列追加在表尾（飞书不支持 API 指定列位置，可手动拖动列序）。

## 开发

```bash
npm install
npm run dev      # 本地开发（飞书插件环境需公网可达，建议直接用 Pages 预览）
npm run build    # 产物输出 dist/
npm test         # 零框架回归测试（46 项断言）
```

## 探针

部署后在目标表的插件环境中打开 `probe.html`，一键实测：addField 返回结构、写文本格式（字符串 vs 富文本数组）、`getRecordsByPage(viewId, stringValue:true)` 返回、建列后写入的延迟容忍。主代码已做双格式兜底，探针用于确认与排障。

## 安全

- API Key 仅存本浏览器 localStorage，仓库与代码不含任何密钥。
- 导出的配置 JSON 自动剔除 API Key。
